# SSH 控制台

AgentDeck 的可选服务器控制台，使用工作台插件接口 v2。

## 安装

在本仓库根目录运行 `npm ci --ignore-scripts` 和 `npm run build`。在支持 v2 的 AgentDeck 中打开「插件」，选择本插件的 `dist` 目录安装，再启用。后续选择新构建目录再次安装即可更新，数据保留。

卸载移除插件程序，保留插件数据；重新安装后继续使用。升级自内置版本时，首次运行将旧服务器档案和密文逐文件迁入插件数据目录，成功后移除原件；用户的 `~/.ssh/known_hosts` 沿用原文件。

## SSH 控制台

SSH 控制台 是可选安装的服务器管理插件，启用后可从侧栏打开。先从选择器选择服务器，再用标签在多台已连接服务器间切换。无需创建本地项目；服务器档案可以手动添加或从 `~/.ssh/config` 导入。

### 页面与操作

| 页面       | 用法                                                                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 概览与进程 | 查看 CPU、内存、1/5/15 分钟负载、各挂载点的占用与可用空间，以及 GPU 利用率和显存。已知核数时显示每核负载；进程表可折叠，显示系统进程及按卡分组的 GPU 进程                                                     |
| 文件       | 通过面包屑或路径进入目录，前后导航保留最近 50 次成功访问；浏览名称、修改时间等元数据和文本预览。目录和预览均只读                                                                                              |
| 终端       | 同一台服务器可开多个终端。分屏优先使用另一已开终端，只有一个时可新建；点击窗格后可在该位置换标签，取消分屏保留当前终端。`Ctrl+F` 或 `Meta+F` 在本机回滚缓冲中查找，显示高亮与命中序号，关闭查找后焦点回到终端 |

只有当前可见且已连接的服务器页面发起监控：概览与进程的刷新间隔为 2 秒。读数缺失与过期分别显示。切回对话、切项目或切服务器不结束 shell；返回时接回仍在运行的终端。终端输入失败时保留已收到的输出，未确认的按键不会重发。若连接已结束，需新开终端。

关闭终端只结束对应 shell；断开服务器会回收该服务器的通道。停用插件前提示将关闭控制台及其中的终端。成功停用会释放控制台的通道和页面状态，保留服务器档案、保存的凭据和共享连接；取消不会关闭终端。若清理完成后保存失败，插件可能仍显示为启用，已经关闭的终端需要重新打开。重新启用后重新选择服务器，按需新建终端。

### 实现与资源约束

- 服务入口：`/api/ssh-targets`、`/api/ssh/*` 管档案、认证和信任；`/api/ssh-console/:serverId/*` 管控制台。后端以档案的稳定 alias 定位，最多 128 条档案，以主机、端口、账号去重，revision/expected 快照保护并发修改。导入读取 SSH 配置文件，保留不支持的选项提示。
- 支持已有私钥或密码；未知主机的 SHA-256 指纹经用户确认并写入 `known_hosts` 后，才使用凭据连接。一次性挑战有效 2 分钟，最多同时保留 32 项；密钥变更或吊销时拒绝连接。私钥正文留在后端。密码仅保留在内存或使用当前 Windows 用户的 DPAPI 加密，编辑时显式读取且返回 `no-store`。
- 底层复用 SSH 连接，exec、SFTP 和 PTY 使用独立通道。断开或认证变化后递增连接代次并失效旧租约，结束、取消或超时只清理对应通道。应用退出时关闭连接池。
- 监控用 `/proc`、`df`、`ps` 和 `nvidia-smi` 等远端已有接口，单次采样超时 25 秒。只读命令共用 `console/command.ts` 的租约通道及按代次区分的缓存。文件页使用 SFTP，目录最多 400 项，文本预览最多读取开头 256 KiB，超限标明截断。通用限额见 [SSH 协议常量](src/shared/console.ts)。
- 后端每台服务器最多 6 个 PTY，全局 32 个，输出保留最近 512 KiB。HTTP 读取返回 base64 字节和 `nextSeq`，浏览器消费后才推进；游标早于保留范围时重置。输入单帧最多 32 KiB、待写 256 KiB。xterm 直接接收字节，未知退出码保持为空，多行粘贴需要确认。终端查找只搜索本机 5000 行回滚缓冲，不向服务器发命令，高亮最多 1000 处，更多命中仍可计数、跳转。

## 开发

前端在 `src/web`，后端在 `src/server`，共用协议在 `src/shared`。页面自包含；后端与运行依赖打包进 `backend.cjs`，由宿主启动独立进程，无需在用户机器另装依赖。

运行 `npm test` 验证现有连接、凭据、文件、监控和终端回归。`scripts/fixtures` 提供合成 SSH 服务器，不读取真实服务器配置。
